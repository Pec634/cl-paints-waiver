LOCAL SPEECH TO TEXT - WINDOWS (64-bit)

1. Extract the whole ZIP to a folder you can write to, such as Documents.
2. Open the extracted LocalSpeechToText folder.
3. Double-click LocalSpeechToText.exe. No Python installation is needed.

Keep the _internal folder beside the EXE. Do not run the EXE inside the ZIP.
The first launch can take a little time while the speech libraries load.

Select a microphone, click Start recording, then Stop & transcribe.
You can also use Open audio to transcribe an existing recording.
The selected speech model downloads on first use, so internet is initially
required. After that, choose Offline only to use the downloaded model.
No API key or paid subscription is needed. Processing runs on this computer.

Models, recordings and saved workspaces are stored beside the EXE in
models, recordings and data. Keep the app in a writable folder.
Imported audio must remain in its original location for playback.
If your folder is synced by OneDrive, its recordings and transcripts may sync.
Speaker labels and transcripts are estimates: review them against the audio.
Use Save text or Export Word to save a transcript where you choose.

This package does not include the creator's recordings or saved transcripts.
