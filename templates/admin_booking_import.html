Import bookings

Back to bookings · Availability calendar

Upload → review and edit → import. We match recognised columns automatically. Nothing is saved until you confirm.

1. Choose a file

CSV / TSV (UTF-8), Excel (.xlsx, first worksheet), or JSON (array of objects or a “bookings” array). Up to 200 bookings, 500 columns and 2 MB. Use one booking per row and headings in the first row.

Dates: YYYY-MM-DD or DD/MM/YYYY. Times: HH:MM, UK local time. Required: first name, last name, email, and a date, start time, finish time and venue for each event day. Date of birth is required for private individuals and optional for business clients. Each booking can include up to 10 dates. Review, add or remove days before importing.

Multiple dates can come from an events array in JSON, numbered columns such as event_date_2 / start_time_2, an additional_event_dates column (same details as day 1), or linked EventDetails worksheets in the legacy Excel export. Separate booking rows stay separate bookings.

New bookings default to Under Review. Consent and signatures are only recorded when supplied; imports do not send emails or create payment records. Existing bookings are never overwritten. Duplicate email, event date and start time combinations are rejected.

    Adjust automatic column matching (optional)

    Choose a different source column if needed. Extra spreadsheet columns are ignored. Changing matches only affects the preview when you rebuild it; rebuilding replaces any preview edits.

    3. Review and edit

    Expand each booking to edit any field. Remove rows you do not want to import. Going back to column matching rebuilds the preview and replaces your edits.
