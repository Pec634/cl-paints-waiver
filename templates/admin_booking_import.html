Import bookings

Back to bookings · Availability calendar

Upload → match columns → review and edit → import. Nothing is saved until you confirm.

1. Choose a file

CSV / TSV (UTF-8), Excel (.xlsx, first worksheet), or JSON (array of objects or a “bookings” array). Up to 200 bookings, 500 columns and 2 MB. Use one booking per row and headings in the first row.

Dates: YYYY-MM-DD or DD/MM/YYYY. Times: HH:MM, UK local time. Required: first name, last name, date of birth, email, event date, start time, finish time and event address. Leave optional details blank when unknown. Import each event date separately.

New bookings default to Under Review. Consent and signatures are only recorded when supplied; imports do not send emails or create payment records. Existing bookings are never overwritten. Duplicate email, event date and start time combinations are rejected.

    2. Match booking form fields

    For each booking form field, choose the matching column from your file. Extra spreadsheet columns are ignored unless you choose to preserve them below. Your spreadsheet does not need the same number or order of columns as the booking form.

    3. Review and edit

    Expand each booking to edit any field. Remove rows you do not want to import. Going back to column matching rebuilds the preview and replaces your edits.
